# Specs

Test plans and exploratory-testing results, one pair per module.

| File pattern | Contents |
|---|---|
| `<module>-test-plan.md` | Scenarios derived from the user story in `user-stories/scrum-<module>.md` |
| `<module>-exploratory-results.md` | Findings from the exploratory pass, including defects; screenshots live in `test-reports/evidence/` |

The final execution report for each module goes in `test-reports/<module>-test-report.md`.

`candidate-management.md` and `candidate-delete-test-plan.md` predate this naming convention and are kept as-is because test files reference them.
